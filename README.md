## 💻 プロジェクト概要

[プロジェクト概要を記載]
C# コンソールアプリ+SQLiteを使用した家計簿アプリです。

支出データをローカルの SQLite に保存し、  
「追加する」「内容を変更する」「削除する」「一覧を見る」といった  
家計簿として必要な基本操作を行うことができます。

「まずは小さく動くものを作る」をテーマに、
後から機能を拡張しやすい構造を意識して開発しています。

---

## 🛠 技術スタック

- **言語:** C# 13.0
- **フレームワーク:** .NET 9.0
- **IDE:** Visual Studio Code
- **バージョン管理:** Git/GitHub（SourceTree を使用）
* **データベース: SQLite**

### 実装機能
#### 支出の追加  
- 日付  
- 金額  
- カテゴリ  
- メモ  
→ 入力内容を SQLite に保存

#### 支出の編集  
1. 一覧を表示  
2. 編集したい項目を選択  
3. 値を入力  
4. SQLite の該当レコードを更新

#### ● 支出の削除  
1. 一覧を表示  
2. 削除したい項目を選択  
3. 削除確認  
4. SQLite のレコードを削除

## 💡 工夫した点・技術的アピール

[開発において意識した点、工夫した点などアピールポイントを記載]
- **小さく作る構造**  
  最初は必要最低限の機能だけを実装し、  
  後から機能を追加しやすいようにコードを分割・整理しています。

- **SQLite を使った軽量なデータ管理**  
  外部サーバーを必要とせず、ローカルで完結するため、  
  環境構築が簡単で扱いやすい。

- **読みやすさを意識したコード**  
  初めて読む人でも理解しやすいよう、  
  メソッド名・変数名・コメントを丁寧に記述しています。

- **ブランチ運用の工夫**  
  開発作業は`feature/add-kakeibo-app`ブランチに集約し、  
  完成後にメンターの方にmainブランチへマージしていただく流れで進めています。  
  作業内容を一つのブランチにまとめつつ、  
  mainブランチを安全に保つことができます。
